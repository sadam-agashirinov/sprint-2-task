# pymongo-api

## Как запустить

Запускаем mongodb, шарды, реплики и приложение

```shell
docker compose up -d
```

Заполняем шарды данными и конфигурием mongo router

```shell
./scripts/init.sh
```

## Как проверить

### Вариант проверки через скрипты
#Выведить количество записей в шарде №1
```shell
./scripts/show-count-shard1.sh
```

#Выведить количество записей в шарде №2
```shell
./scripts/show-count-shard2.sh
```

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080
Увидите вывод json файла с данными.
В конце увидите будет пункт cache_enabled со значением true.
А так же второй и последующие запросы для эндпоинта /<collection_name>/users будут выполнятся быстрее.

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080
